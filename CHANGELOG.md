# Changelog

All notable changes to `Lock Selection` are documented here.

## [v1.14] - 2025-04-05
### Added
- Support for individual locking per object
- Button in Tool Panel and Header
- Shortcut `Alt + K`
- Full restoration of selection by type

### Fixed
- Recursive call protection
- Compatibility with Blender 4.2
- Stability during transformation (`G`, `R`, `S`)

## [v1.13] - 2025-04-04
### Added
- Multiple selection sets support

## [v1.12] - 2025-04-03
### Added
- Initial working version
- Basic selection lock
